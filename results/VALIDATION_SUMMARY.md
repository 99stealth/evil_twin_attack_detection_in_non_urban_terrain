## V6 — Session-level permutation test

1000 permutations, primary protocol, fixed `ExtraTreesClassifier(n_estimators=300)`.
Full table: `results/permutation_tests.csv`; figure: `figures/permutation_antenna.png`.

| Task | Observed acc | Null mean | Null 95th pct | p-value |
|---|---|---|---|---|
| Point Prediction | 0.736 | 0.102 | 0.180 | 0.001 |
| Antenna Prediction | 0.336 | 0.170 | 0.243 | 0.002 |

Both **significantly above chance** (p < 0.005): even though Antenna Prediction's
leave-one-point-out accuracy (0.336) looks low against 1/6 = 0.167 naive chance, the
session-permutation null (which preserves the point-conditional class balance) is
centered at 0.170 — so 0.336 is roughly double the *true* null expectation, not
"barely better than guessing". Antenna, permuted only within sessions sharing the same
point (acceptance check #3 — verified in the notebook's last cell): each permuted
session's label is constant across its rows, and each session's own point is preserved.

## V7 — No-imputation sensitivity variant

5s grid with `dropna()` instead of nearest-neighbour interpolation
(`eval_protocol.build_dataset(..., impute="none")`). Full table:
`results/no_imputation_variant.csv`.

| Task | Model | Rows (imputed → no-imputation) | Acc (imputed) | Acc (no-imputation) | Δ |
|---|---|---|---|---|---|
| Attack Detection | KNN | 2131 → 442 | 0.988 | 0.975 | −0.013 |
| Point Prediction | KNN | 571 → 116 | 0.743 | 0.750 | +0.007 |
| Antenna Prediction | XGBoost | 571 → 116 | 0.363 | 0.388 | +0.025 |

Imputation is not inflating the headline numbers: dropping the ~33% imputed rows
changes accuracy by at most 0.025 in either direction (Point/Antenna actually improve
slightly without the interpolated rows, plausibly because they remove noisy
near-duplicate values; Attack drops marginally, likely just fewer test rows / fewer
attack sessions retained — only 37/48 survive the stricter cycle-alignment).
